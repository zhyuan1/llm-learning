# Agent Architectures

本目录记录一次关于“Agent 存在的主流架构、差异与相同，以及每种架构适用范围”的 Quick Reference 研究。

## 目录结构

- `notes/research-log.md`：本次研究过程记录
- `notes/quick-reference.md`：整理后的结构化结论
- `sources/primary/SOURCES.md`：一手资料索引
- `sources/primary/*.md`：一手资料的本地记录（原文副本或提取笔记）

## 这次研究的核心问题

1. 主流 Agent 架构有哪些
2. 它们的共同点和核心差异是什么
3. 每种架构分别适合什么问题
4. 如何避免把“框架选择”误当成“架构选择”

## 当前结论（一句话版）

分析 Agent 架构时，最好分成两层：

1. **推理/编排层**：谁决定下一步怎么做
2. **运行时/基础设施层**：状态放哪、怎么恢复、怎么隔离、怎么扩展

很多框架其实横跨多种架构形态，应该先判断任务类型，再选框架。
