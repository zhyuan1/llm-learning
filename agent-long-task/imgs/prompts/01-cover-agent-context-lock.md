# Cover Prompt: Agent 跑着跑着就不对了，究竟在哪里

Flat-vector conceptual cover image for a technical article about AI Agent context locking failures in long-horizon
tasks.

## VISUAL CONCEPT

The core metaphor: an AI agent (represented as a small robot or geometric humanoid figure) running along a timeline
track, but the track ahead gradually curves inward and locks into a spiral — it cannot break free and course-correct.
The "context" accumulates as stacked layers behind the agent that grow heavier, slowing and constraining forward motion.

- **Left zone (40%)**: The agent's starting point — clean open track, bright cyan lines, small robot silhouette moving

- **Center zone (35%)**: The critical transition — context layers start stacking up (shown as flat rectangular blocks

- **Right zone (25%)**: The locked state — the agent is trapped in a tight loop/spiral made of context blocks, a subtle

Visual flow: left-to-right narrative of "running → accumulating → locked"
